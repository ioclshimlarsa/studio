# **App Name**: LibraryLite

## Core Features:

- Role-Based Authentication: Admin and user role-based secure login using unique IDs and passwords.
- Book Browsing: Display available book details including title, author, and language.
- Request Management: Handle and manage the book requests with approval/rejection workflow.
- Automated Status Updates: Automated update book statuses.
- AI-Powered Reminders: AI tool to generate and send gentle personalized reminders (leveraging customer issue history to improve tone and format) to users for overdue books. 
- History Tracking: Enable users to view personal history of issued/returned books and due dates.

## Style Guidelines:

- Primary color: Calm blue (#64B5F6) to inspire trust and organization.
- Background color: Light gray (#F0F4F7) for a clean, uncluttered feel.
- Accent color: Muted purple (#9575CD) for highlighting important actions and notifications.
- Body and headline font: 'PT Sans', a modern humanist sans-serif for readability and a touch of warmth.
- Use simple, recognizable icons to represent different actions, such as requesting, returning, and browsing.
- Prioritize a clean and intuitive layout for ease of navigation and to ensure the app is easy to use for non-technical users.
- Employ subtle animations to indicate changes and status updates, keeping users informed without being intrusive.
